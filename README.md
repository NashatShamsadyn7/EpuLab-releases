# EpuLab — downloads

**EpuLab** is an electronics and digital-logic lab for students on Windows: build circuits, switch them on and measure them like on a real bench (oscilloscope, function generator, logic analyzer, Bode plotter, 74xx chips, 555, guided labs, truth tables and K-maps).

This repository holds **installers only**; the source code is private. EpuLab checks this page for new versions and offers to update itself.

## Download
Open **[Releases](../../releases)** and download `EpuLab-<version>-Setup-x64.exe`.
Requirements: Windows 10/11 64-bit with .NET Framework 4.8.
Every release includes `SHA256SUMS.txt`; the built-in updater refuses any file that does not match it.
